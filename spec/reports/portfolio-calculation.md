# Розрахунок звіту по портфелю

Звіт відкривається зі списку на вкладці «Звіти». Розрахунок — `src/screens/reports/portfolio/portfolioReport.ts`, екран — `portfolio/PortfolioReportScreen.tsx`, рядки екрана й PDF — `portfolio/portfolioReportRows.ts`, HTML документа — `shared/reportPdf.ts`.

**RPORT-01.** Для кожної валюти з позиціями результат використовує `resultsByCurrency`: вкладення включають усі купівлі, зокрема позиції без даних облігації; виплати, надходження від продажу та чистий дохід обчислюються за правилами гаманця.

**RPORT-02.** Заплановані вкладення — сума купівель із прапорцем `planned`, навіть якщо їхня дата минула; вони входять у підсумок і для позицій без даних облігації.

**RPORT-03.** Фільтр «усі» включає всі позиції, «погашені» — лише погашені, «в обігу» — позиції в обігу, заплановані та з невідомим станом. Повністю продані позиції залишаються в історії та входять лише у фільтр «усі».

**RPORT-04.** Частка вкладень позиції — її вартість, поділена на вкладення валюти, включно з позиціями без даних. Якщо вкладень немає, частка невідома. Позиції впорядковані за датою погашення, без даних — останні.

Сценарії продажу, непідтвердженої купівлі та відсутніх даних описані в `portfolioReport.test.ts`.

**RPORT-05.** На окремому екрані користувач обирає стан, валюту та облігації. Звіт отримує вибір у параметрах маршруту й показує станом на сьогодні підсумки за валютами та позиціями, зокрема продажі, заплановані вкладення і попередження про неповні дані.

**RPORT-06.** Кнопка поширення створює PDF з тих самих рядків, що видно на екрані, з назвою плану, датою, обраним станом і попередженням про збережені дані НБУ, якщо оновлення не вдалося. Кнопка недоступна, коли результат порожній. Назва плану та інші дані екрануються в HTML.
